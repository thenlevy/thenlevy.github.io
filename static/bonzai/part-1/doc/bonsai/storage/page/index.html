§Page layout

+--------+---------------+----------------+--------------+---------+
| header | line pointers |→  free space  ←| tuple data   | special |
+--------+---------------+----------------+--------------+---------+
0        24          pd_lower         pd_upper     pd_special    8192

Fields are little-endian. Postgres uses the machine’s byte order, which is little-endian on x86-64 and ARM64, so there the bytes match Postgres’s.
